How to install an IPTV player on Fire TV Stick

  1. Search for the free Downloader app in the Amazon Appstore and install it.
  2. Open Settings › My Fire TV › Developer options and allow Install unknown apps for Downloader. No Developer options? Go to About and click the device name 7 times.
  3. Open Downloader and type the code 4704271, then press Go.
  4. Press Install, then Open.
  5. Add your playlist: type your M3U link or Xtream Codes login, or scan the QR code with your phone and type it there.
